# 慢三拍 · 安卓离线版 1.0.0

安装包：`慢三拍-v1.0.0.apk`

## 安装与游玩

1. 将 APK 文件发送或复制到安卓手机。
2. 下载保存后，用手机的文件管理器点开 APK 安装。
3. 如果手机首次安装此来源的 APK，按系统提示为该来源授权安装；本包为自行签名版本，未通过应用商店分发。
4. 安装后，点击桌面上的「慢三拍」开始游戏。

系统最低要求：Android 8.0（API 26）。iPhone 无法安装 APK。

八个关卡、图形与声音均内置，不需要网络、VPN或 ChatGPT 登录。APK 未声明联网、文件存储、相机、麦克风等权限。

点击屏幕方向按钮或在棋盘上滑动来移动，点「等一拍」让回声追上来。支持撤销、提示、声音开关与横竖屏。系统返回键先关闭玩法说明，再询问是否退出。

完成关卡和最佳步数保存在本机。重新启动时从当前关卡起点开始；卸载或清除应用数据会清除进度。网页版本与 APK 的进度各自独立。
