# 慢三拍 · Three Beats Later

一款关于移动、等待与过去的自己合作的短篇解谜游戏。八关，无倒计时；电脑键盘与手机触控均可游玩。

## 运行

直接双击交付的「慢三拍.html」即可离线游玩，无需安装。

开发源码使用原生 HTML/CSS/JavaScript，无第三方 JavaScript 依赖。安装 Node.js 后在项目目录运行 `node preview.mjs`，访问 http://127.0.0.1:4173 。运行 `node test-engine.js` 验证核心规则。

## 操作

- 方向键或 WASD：移动。
- 空格：原地等待一拍。
- Z：撤销，包括回声和整个历史队列。
- R：本关重来。
- 支持屏幕方向按钮与棋盘滑动。
- 提示只给出当前状态可通关的下一步。声音默认关闭，可手动开启。
- 进度和最佳步数保存在当前浏览器中。

## 规则

金色角色走一步，青色回声就重走三次有效行动之前的位置。等待也会推进回声；撞墙和撞关闭的门不消耗回合。玩家与回声分别同时站在金色与青色花座上即通关。

任何角色压住方形机关时，所有同纹样的门打开。门在行动前检查机关，回声按历史位置回放，可以穿过关闭的门。在门内可以离开，不会被困住。回声和玩家允许重叠。

## 设计调研与取舍

2026-10-29 查阅了以下原始来源：

1. [PlayStation 官方：Introducing echoshift for PSP](https://blog.playstation.com/2010/02/05/introducing-echoshift-for-psp/)：过去动作回放、回声踩开关已有先例。《慢三拍》不把回声协作宣称为首创，而采用固定三步的连续延迟，省去录制阶段和时间线重启。
2. [开发者：A Good Snowman Is Hard To Build](https://draknek.itch.io/a-good-snowman)：开发者页面标注互动教程、无文字与色盲友好。本作据此采用递进式短关、角色形状区分、可见的三格回声预告，让规则可观察。游戏文字与关卡为本次独立创作。

本作的设计重点：同一个「等待」动作既能让回声追上你，也能提前安排回声将来的停留。后续关卡把这个时间关系用于开门和机关接力，持续扩展同一规则。

视觉全部由代码绘制：纸色背景、深绿花园、金色种子与青色回声。没有使用外部图像或音频素材；声音由 Web Audio 合成。联网版标题可加载 Google Fonts 的 Noto Serif SC；离线版使用系统字体。

## 验证

- 8 座花园均以广度优先搜索验证可解；最短步数为 4、6、6、7、9、12、18、15。
- 自动检查覆盖三步延迟、等待、不可走移动、开关、关门后离开、回声穿门、中途求解与不可达状态。
- 浏览器实际逐关完成全部八关，验证解锁、撤销、重来、空格等待、说明弹窗和提示。
- 已检查 390 × 844 手机视口，无横向内容溢出。

## 文件

- `dist/index.html`：界面。
- `dist/style.css`：响应式视觉。
- `dist/engine.js`：关卡、纯规则与求解器。
- `dist/app.js`：交互、SVG 渲染、进度与声音。
- `test-engine.js`：逻辑验证。
- `preview.mjs`：本地静态服务器。
- `build-offline.mjs`：生成无需服务器的单文件离线版。
