# 慢三拍 · 微信真机测试清单

本清单供账号和 AppID 准备好后执行。目前本地源码检查或模拟运行不能代替微信真机测试。每项应记录设备型号、系统版本、微信版本、基础库版本及结果。

建议至少覆盖一台安卓手机和一台 iPhone；若只测试其中一种平台，交付说明应保留相应限制。

## 导入与首次启动

- [ ] 使用真实小游戏 AppID 导入，确认项目类型是“小游戏”。
- [ ] 编译成功，控制台没有语法错误或找不到文件的异常。
- [ ] 有权限的账号能扫码预览或进入真机调试。
- [ ] 首屏能显示完整棋盘，八个关卡的标题和图形没有乱码。
- [ ] 顶部内容避开微信胶囊菜单、状态栏、刘海；底部按钮避开手势区。
- [ ] 在常见窄屏、长屏和高像素比设备上，按钮可见且触控位置准确。
- [ ] 游戏启动后切换网络状态，已内置的单机关卡仍可游玩；区分首次打开代码包的下载需求。

## 玩法与进度

- [ ] 第一关连续向右四步过关，回声延迟三次有效行动。
- [ ] 撞墙／关闭的门不计步，也不推进回声。
- [ ] 等待保持玩家位置，同时推进回声。
- [ ] 触控按钮与棋盘滑动每次只执行一个预期动作。
- [ ] 多点触控、短距离轻触、触摸取消不会产生意外移动。
- [ ] 撤销同时恢复玩家、回声、历史队列和步数。
- [ ] 机关开门、回声穿门和离开关闭门的行为与说明一致。
- [ ] 八关均能完成，通关后解锁下一关，末关能重新开始。
- [ ] 提示只给出可通关的下一步，不自动替玩家移动。
- [ ] 重来只重置当前关卡，不清除已完成记录和最佳步数。
- [ ] 退出再进入后，已完成关卡、最佳步数、最近关卡和声音偏好保留；当前关卡从起点重新开始。
- [ ] 清理对应本地缓存后，游戏能够以新存档正常启动。

## 生命周期与声音

- [ ] 帮助弹窗可以关闭，弹窗显示时背景按钮不会误触。
- [ ] 切到聊天或将微信放后台，再回来不会多走一步、重复计步或重复绑定触控事件。
- [ ] 声音默认状态符合界面标示，打开／关闭后立即生效。
- [ ] 电话、闹钟、语音聊天等系统声音中断期间，不会继续异常播放。
- [ ] 中断结束并返回游戏后，按当前声音偏好正常反馈。
- [ ] 静音键／系统音量的表现经过实际 iPhone 和安卓验证，不把模拟器声音视为真机结论。

## 分享与体验版

- [ ] 主动点分享后出现微信分享界面；取消分享不影响游戏进度。
- [ ] 分享卡片的标题、图片比例和内容正常，无无关域名。
- [ ] 从卡片进入的有权限体验成员能打开游戏。
- [ ] 未授权体验成员打不开时，按体验版权限处理，不误判为代码故障。
- [ ] 分享不会成为过关、解锁或获得提示的条件。
- [ ] 正式发布后，另用非开发／体验成员账号验证公开进入和分享。

- [ ] 记录实际已测设备与未覆盖平台。
- [ ] 上传的版本与本次通过测试的代码一致。
- [ ] 填妥运营主体、联系信息、隐私保护指引及适龄提示。
- [ ] 在账号后台完成所需备案和资质流程，并确认版本审核及发布状态。
